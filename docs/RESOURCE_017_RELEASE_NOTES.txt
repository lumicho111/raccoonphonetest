• iCity UI 按本轮约定调整：原版截图提取的底栏图标、四列圆头像直接加入/移出、主页原位改头像背景、精简资料和设置、顶部安全区、独立生成/保存与可滚动方形文字配图。
• 移除旧版日记入口、重复“写一篇”、评论区与回应、多人共同日记、邀请等待。原有日记数据保留。
• 个人自动日记按角色独立配置，默认关闭；保留人设、上下文、核心及长短期记忆等生成参考。发布范围由角色结合心情自主决定。每篇标记世界/好友/私密。
• 1v1交换日记直接加入，单独设置自动回信与延迟；合并等待中的追加内容，不重复排队。所有生成保留确认与打断；失败/打断不保存半篇、不重置个人原冷却。
• 世界刷新追加保留旧内容，角色可自主喜欢本批陌生人日记；主页分公开日记/喜欢。点赞缓慢累积，世界随日记变旧衰减、好友随机、私密无点赞。不做评论或自动共享事件。
• 私密显示灰色封面，连点尝试偷看。25%被发现时触发Chat按人设回应，成功不通知。自己的私密单击打开编辑。
• 反查加入iCity实际页面：角色可阅读user日记，私密需弹窗允许或概率破解后才能获得正文；可按人设继续请求，也可能放弃。可看见尝试过程与展开动画。
• 明确提到iCity标题、引用或喜欢记录时按权限查找对应日记，不新增向量API。
