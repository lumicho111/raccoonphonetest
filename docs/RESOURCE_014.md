兔版 Float 资源更新 014（适用 APK 1.0.6 / build8）

1. 手记改为纯文字日记空间：五栏为日记本、动态、写日记、消息、我的；动态含世界、朋友、喜欢。内部独立日间/夜间模式并保存选择，不跟随全局主题。
2. 书架：user 和每位角色各有个人日记本；新增多人共同日记和1v1交换日记，邀请接受前不能读写，默认仅成员可见。个人日记逐篇可设世界、朋友、指定朋友、仅自己。
3. user 可以写、编辑、删除文字日记。支持世界日记浏览、点赞评论、互动通知、好友申请和导演管理角色间好友关系。没有站内私聊，也没有图片/GIF/视频日记发布入口。
4. 个人主页支持头像、背景、昵称、账号、简介和默认分享范围。马甲按账号身份展示；外界评论不注入作者私人日历、聊天或日记。已知朋友圈路人账号可沿用为独立日记账号，不自动成为好友。
5. 保留原日记生成引擎、人设/记忆/世界书等参考逻辑及定时服务。共同/交换日记手动生成时额外提供本日记本成员可见的历史内容。原日记数据保留并按私密迁移，字体、翻译和原私密记录管理入口保留。
6. 朋友圈：修复单独发布实况/GIF时媒体区域被遗漏而显示空白；发布前实况预览为1:1居中裁切，发布后按原始宽高比完整展示，不再限制360px高度。
7. 动态照片试验导入：Chat和X的实况入口可选择原始 JPG 动态照片；朋友圈选图可识别 JPG 内嵌视频，提取后沿用8秒/抽帧/单次播放逻辑。只试验支持含完整内嵌MP4视频的JPG，不保证所有vivo或其他品牌私有封装兼容；静态照片不伪装为实况。
8. 检查更新新增连接中提示和25秒等待超时反馈，避免无反馈等待；未连接用户手机，尚未确认此前拉取无响应的根本原因。

lib/browser-collection.ts、原日记生成引擎和定时服务保持字节一致。保留013及此前状态栏修复。
验证：TypeScript、手机生产构建；日记权限/邀请/迁移/撤销/删除、动态照片提取边界；浏览器发布、评论点赞、主题保存、共同日记、主页及朋友圈实况渲染和比例验证；原Java更新器校验和激活/回退测试。
未进行真实Android安装或真实LLM API端到端生成测试；vivo原生动态照片待完整原文件实测。
安装：设置 → 关于与更新 → 导入更新包，选择本ZIP，校验后安装并打开。无需重装或清除数据。
