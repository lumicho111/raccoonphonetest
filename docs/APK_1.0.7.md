# 兔版 Float APK 1.0.7 / build9

覆盖安装到原 app.ii.phone，沿用原签名。无需卸载或清空数据。包含此前资源014及本次电话/iCity修改。

## 电话（独立 Phone App，不改 Chat 语音通话）

- 参考两排三列布局：免提／静音／重回，台词／结束／输入。
- 免提接原生 AudioManager，语音用原生 MediaPlayer 的通信音频用途播放，在可用设备间选择听筒、耳机或扬声器；失败时提示错误，不显示虚假成功。挂断或销毁页面恢复原音频模式，清除本次设备选择。
- 静音为禁用占位，未接入电话页的麦克风、录音或语音识别。无需新增通讯录或通话记录读取权限。
- 台词与输入分别开关；输入有发送自己的话、让角色回复两项操作。重回重新生成角色最近一轮，移除旧一轮避免重复。
- char 发起来电时提前准备第一句话，接通后才显示／播放；未接、拒接不发送。user 主动拨出，接通后等待 user 首句。
- 为迟到的接听决策、模型回复、TTS结果添加通话ID／生成批次检查，挂断后不复活、不继续播放。

## iCity

- 桌面名称改 iCity。日间／夜间独立保存；参考浅灰复古风格，方角内容区、细分隔线、分段顶栏。
- 顶部为状态栏保留空间。底栏五个纯图标，中间钢笔按钮悬浮，选中项加深并标蓝点；消息保留铃铛。
- 小弹窗居中，轻微淡入缩放；发日记为全屏编辑，正文自动聚焦。
- 日记本顶栏圆头像和＋引入角色。只加入选中的角色并加为user朋友；移出不删旧日记。左右滑动切换账号，只显示本人拥有／参与的个人、共同、交换日记本。点击头像进个人主页。
- 个人资料：头像、背景、昵称、账号、引号装饰签名、位置、默认分享范围、日记语言。统计栏收紧。无市民称号、勋章、会员和站内私聊。
- 日记支持可选标题、照片、手动地址、目标日记本、逐篇权限。相册选图或使用用户已配置的生图API；缩略图1:1居中裁切，点开完整图。
- 正文下方、图片上方有无箭头翻译按钮，展开／收起中文译文；详情里也保留原文。
- 点动态进评论，爱心点赞，气泡评论，显示日期，竖三点编辑／权限／删除。内置两条可删除的示例动态，只添加一次。
- 原日记生成的人设、世界书、记忆等参考来源及组装流程不变；定时服务不变。仅添加账号明确选择的输出语言覆盖。lib/browser-collection.ts 保持字节一致。
