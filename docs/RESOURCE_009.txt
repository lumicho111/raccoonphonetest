兔版 Float 资源更新 009（适用 APK 1.0.6 / build8）

安装：设置 → 关于与更新 → 检查更新。无需重装 APK。

• 模拟状态栏改为读取设备电量及充电状态，电量变化和回到应用时更新。使用 Android WebView 的 Battery Status API；不支持读取的网页环境显示空电池，不伪造电量。
• 长按多选底栏跟随 Chat 日夜模式：深色底浅色图标、浅色底深色图标，禁用项保持可辨认。
• 聊天列表左滑操作固定在聊天行后方，跟手逐步露出，收回后不透出按钮。
• 隐藏聊天继续留在列表原位，以变浅表示隐藏；取消隐藏立即恢复，不需从联系人重新打开。查手机时的隐藏判定保持原规则。
• 修正“偷偷查看运行记录”入口字号和排版，以及深色 Chat 状态栏时间对比度。
• 浏览器移除角色端重复顶部安全区，普通页面背景延伸至状态区；网站页面保持深色。详情与设置底部均可完整滚动查看。
• 角色端网站搜索栏只展开/收起搜索记录，禁用输入与搜索按钮，仅刷新生成。刷新结合人设、上下文、记忆、独立偏好及共享提示词，生成5–8条搜索记录和5–8条浏览记录。
• 自定义长提示词在用户端与角色端共享；内容组合的喜欢/排除设置各自独立。
• 角色端收藏持久保存，也可手动收藏和删除。每次刷新可按角色偏好从上一批浏览记录中选1–2条加入收藏；首次可从新批次选择。收藏最多20条，满额时优先随机替换自动收藏；手动收藏优先保留，全部手动收藏时不自动挤掉它们。
• 两端详情页加入与收藏并列的删除入口：删浏览记录不会连带删收藏，删收藏不会连带删浏览记录。
• 生成任务不再固定为恋爱/影视题材；仍保留JSON格式、条数、翻译字段、偏好排除和非露骨内容边界。

验证：TypeScript、生产构建、浏览器数据/电量监听测试、查手机与反查路由及权限回归；真实组件浏览器交互检查。未使用用户 API 密钥，未作真实 Android 手机实机验证。
