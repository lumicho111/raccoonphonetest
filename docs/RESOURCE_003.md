# 资源 003 · 幕后导演讨论室

适用于兔版float 1.0.4（APK build 6）。这是累计资源更新，可以从内置资源或资源 002 直接安装，不需要重装 APK。更新前建议导出完整数据备份。

- 幕后改为简洁的手机 GPT 风格：顶栏保留对话名，左侧抽屉，右侧新聊天与菜单，移除分享和模型小三角。
- 侧栏分置顶、聊天；支持按标题搜索。长按对话可重命名、置顶、归档、删除。新聊天和退出放到底部，保留深色模式、归档查看和导出。
- 当前对话菜单支持置顶、聊天内查找、归档和删除；归档或删除后返回可用对话，不留下空白页。
- 输入框加号统一为照片、文件、角色、模型四个入口。
- API 与模型在同一个抽屉里选择，沿用全局保存的连接信息，按对话记住选择。模型列表可搜索，也可手动填写。
- 角色资料支持层级多选、统一读取；预览改为可展开的词条，能编辑副本、移除、手动补充资料，再点“发给幕后”直接发送，支持附带问题。不修改原始资料，也不自动持续同步。
- 新增导演伙伴 AI 与角色访谈。默认第三方分析，也可以把演员叫来解释；区分已有依据和可能的解释。两种模式都不推进正式剧情、不回传记忆、不修改人设。
- Word（.docx）和 PDF 在本机提取文字后供模型阅读，图片仍走模型看图。保留文本文件支持。
- 旧幕后对话、附件、归档、深色设置与已有 API 选择保留。

空白页文案：
导演，今天想问什么？
可以和导演伙伴 AI 聊聊，也可以把演员叫过来。
幕后的故事，不会带回幕前。

文件范围：单个附件最多 5MB、每轮最多 9 项；单项文字最多 60000 字符，PDF 最多 200 页。暂不支持扫描 PDF 的 OCR 和旧版 .doc，请改发图片或转换为 .docx/可选中文字的 PDF。模型列表接口不可用时仍可手动输入模型名。

验证：类型检查、网页生产构建、原有线下重回/转发回归及新的幕后迁移/API/访谈/资料边界检查通过。用模拟 API 的手机尺寸浏览器预览检查了长按、标题搜索、聊天内查找、资料多选/编辑/发送、访谈和归档返回；真实 DOCX（含表格）和 PDF 的本地文本提取通过。没有在真实安卓设备上验证本次更新后的全部交互或真实模型输出。
