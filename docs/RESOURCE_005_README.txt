资源005 · 反查手机与聊天界面更新
适用：兔版float APK 1.0.5（native build7）。在设置 → 关于与更新检查资源更新，无须重装APK。本包累计包含资源001至004。

1. 在私聊加号菜单点“让TA查手机”：按人设回应后，角色控制实际页面，可看聊天列表、部分会话、朋友圈、购物车、购物/外卖记录、已有书籍与阅读进度。路径每次由模型选择，每次最多五轮操作；不会改写阅读进度。可在私聊代发并收到回复，群聊本版只查看。
2. 查阅时显示状态、角色原文心声和较小的中文翻译；左上小叉提前结束。主动结束或提前结束后，均回到原聊天生成一次回应。聊天里保留折叠的反查记录；长按删除它清除这次查看的记忆来源。结束回应可正常单独删除。角色代发给其他人的消息，请去对应会话删除；关联日志会同步清理相应内容。
3. 消息列表长按可隐藏/取消隐藏聊天。本人仍能打开；反查角色只有实际寻找并发现以后才知道该聊天。
4. 查手机退出时不再自动安排双方解释。后续正常聊天自然谈起时，双方按人设选择是否私下对账。真实对话同步双方查手机记录与知情来源，可转发实际快照。长按删除对账灰框，关联对账、镜像与自动转发一并删除；原始代发另行删除。NPC对话只归主人手机，不建立NPC独立记忆。
5. 查手机解锁、生成密码弹窗统一黑色风格；修复顶栏重叠及桌面应用弹窗中多出的操作记录。
6. 安卓返回优先关闭弹窗/菜单，再退应用内上一级、再退桌面；桌面才询问退出。
7. 转发详情改为紧凑卡片、气泡随文字长短、点击原文切换翻译，主题跟随Chat；新快照名称用网名，没有时用本名。
8. 多选操作栏改为毛玻璃图标胶囊。可只截勾选消息，省略未选消息且不添加省略提示；背景连续铺满，尽量保留现有CSS、字体和气泡样式。可预览/保存/系统分享，或带图进入朋友圈草稿，由本人发布。外部图片不可读取或设备不支持时会提示，不清空选择。

撤销范围为系统关联记录。后续手工另写的长期记忆、独立导出副本或后续普通聊天，仍按原功能单独管理。

完整源码为累计完整版，不用逐次覆盖旧包。私钥、签名密码、node_modules、编译缓存与测试预览不包含在源码包中，请保留你自己的私人签名备份。APK包名、原签名、数据源与原生基线均保持不变。

已通过类型、生产构建与相关回归检查，并用模拟API在浏览器跑通反查流程。尚未在真实安卓设备或真实模型API上验证；角色行动与台词取决于模型输出。
