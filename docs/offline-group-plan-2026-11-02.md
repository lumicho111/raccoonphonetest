记录日期：2026-11-02。当时范围决定：本版不实装「多人分开写」，群聊只使用「多人一起写」。本文是需求备忘，不代表已实现或已打包。现有最新交付仍为兔版float 1.0.2。

## 本版保留的方向（待实现）

- 群聊线下与单聊线下接齐功能：按场记录、场景时间与进行中/暂停、归档总结、编辑删除、翻译展示及语音。群聊仍为连续群像叙事，每轮对方一个气泡，头像使用群聊头像、名字使用群名。
- 单聊线下 User 显示名优先取朋友圈网名，没有才取本名；Char 保留现有正确逻辑。仅调整展示名称，不把网名替换为人物身份设定。
- User 增加快捷添加语音入口；角色和 User 的实际台词均可使用绑定音色合成原文。译文与旁白不合成。
- 真正说出口的台词使用明确的专用标记，携带说话者、原文及可选译文。最终协议语法待实现时统一。前端展示喇叭、原文、可折叠译文，不额外展示包裹台词的引号。
- 普通引号保留给引用、回忆和复述等普通正文，不再通过引号猜测语音台词；取消英文引号自动识别/兼容方案。普通引号中的旧内容保持普通文本。角色如果实际开口复述，只有明确标记为实际台词时才播放。
- 群像一起写虽然显示群头像，内部台词仍需准确对应各说话者，使用各自音色；不能给所有人的台词套同一个音色。无法确定说话者时不猜测音色。
- 单聊及群聊一起写不新增「重回」。要重写本轮对方正文，删除整段，再点召唤回复生成。
- 用户提供的现有群聊线下预设作为一起写的基础：保留群像去中心化、自然参与、角色间信息边界、不代替 User 输出言行与心理。每轮强制摘要等旧要求需与按场逻辑统一，不能同时要求每轮总结和整场结束才总结。

## 延后方案：多人分开写（仅留存，本版不做）

### 模式及预设

- 未来增加「一起写 / 分开写」两种模式，默认一起写。
- 两套预设均可编辑，按当前模式二选一使用，不得同时注入。不在本版添加分开写开关或空入口。
- 一起写沿用群像连续叙事；分开写由本轮实际参与者分别以自己的视角叙述，不要求全员每轮发言。
- 每个角色只写自己的言行、心理及能感知的信息，不代替别人决定，不重复复述整场；保留群像自主性及不替 User 行动的边界。

### 气泡与身份显示

- 分开写时，每位参与者有自己的内容气泡，使用对应角色头像和群昵称，优先沿用 Chat 设置。
- 一起写仍然整轮只有一个群头像、群名气泡。
- 两种模式都使用与单聊一致的语音台词/译文显示规则。

### 编辑、删除、单人重回

- 分开写的各角色段落可分别编辑、删除、重回。一起写和单聊不增加此功能。
- A、B、C 三段中重回 A，只替换 A，A 仍在第一段，B、C 原文不动，不追加成新的末尾气泡。
- 重新生成 A 时参考此前上下文和已固定的 B、C，保持动作、时间和结果衔接，但不能把 B、C 的内心或秘密变成 A 知道的信息。
- 删除仅删除，不自动生成。重回则保留旧段，待新版成功后原位替换；失败保留原段。
- 全删本轮 A、B、C，再召唤回复，重新生成整轮。
- 单人重回不新增轮次，不额外推进场景时间。只删部分人后再点整轮召唤时，究竟补缺失角色还是生成下一轮，尚未明确约定，后续实现前再确定，不从已有讨论擅自推断。

### 时间与全局暂停

- 一轮的场景时间与「进行中 / 暂停」只显示在该轮最后一个角色气泡下，避免重复。
- 此状态属于整个群聊线下场景，控制所有参与者；不是只暂停最后那个角色。
- 所有角色共用同一场景时钟，不按个人维护不同暂停状态。
