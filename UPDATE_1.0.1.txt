float 1.0.1 更新说明（2026-11-02）

使用方法
1. 先从「设置 → 数据管理」导出完整备份并确认文件保存成功。
2. 安卓用户安装 float-1.0.1-test.apk 覆盖旧版，不要卸载、清除存储或换签名。
3. 源码包为完整源码覆盖包，直接解压到现有工程根目录；保留你自己的 .env、签名文件和部署设置。运行 npm ci 后重新构建/部署。网页端 npm run build；安卓参阅 ANDROID_BUILD.md。
4. APK 和浏览器仍是各自独立的数据空间；安装 APK 不会自动同步浏览器记录。

本批更新
- 数据安全：读取完成前防止默认空值覆盖旧存储；迁移成功后才清旧副本；独立 KV 恢复快照；写入失败提示和部分写入队列重试。保持原包名 app.ii.phone、本地 https://localhost 及签名。
- 消息提示：通知卡片不再跟随小组件透明度；灵动岛居中；Chat → 我的入口统一为「后台通知」。安卓增加本地消息通知权限/展示/点击入口；网页通知保留。
- X / YouTube：身份披露左对齐紧凑行，改为「不披露 / 让对方知道我是谁 / 互相知道身份」，原有知情方向及双向同步不变。
- 设置：安卓页面字体跟随全局缩放；网站地址解释为可选服务配置；锁屏弹窗改为右侧关闭/开关、全宽密码操作和壁纸预览行，统一圆角。
- Chat：移除「我」的头像相机角标，移除全屏 emoji 特效入口及自动播放；普通 emoji/贴纸保留。双语消息点击气泡展开/折叠翻译，保留默认展开设置；链接/按钮/长按/选字不会误切换。
- 短信：双方气泡尾巴向内收；首页顶栏为左侧返回，右侧编辑、设置。
- 在场：固定使用提供的卧室图作底图，保留原模糊效果，不再依赖首个角色头像。
- 追发：原回复可输出隐藏的追发意向和等待秒数；没有标记就不排期，不额外调用模型判断。标记只决定是否/何时追发，正文仍到时生成；沿用次数、群聊等限制和设置中的等待范围（最短项上限300秒、最长项上限600秒）。
- 冒险：只有已关联角色的台词可点击喇叭播放原文；旁白、NPC、译文不读。喇叭跟随原文，保留翻译折叠行为。

验证与限制
- 类型检查、真实 IndexedDB 模拟故障/迁移检查、追发意向检查、现有身份披露/YouTube 返回等回归检查通过；Vite 生产构建、安卓 release 构建及同签名校验通过。检查了内置资源一致性和浏览器预览。
- 没有真实安卓设备升级、后台权限/通知、音频接口或真实模型端到端测试，请先保留备份再试。
- 本地通知仅用于应用仍能运行并收到/生成消息的情形；没有 FCM/其他远程推送服务，强制结束进程后不会因此继续生成或接收远程消息。网页后台机制保持原有实现。
- 恢复快照只是 KV 配置与元数据，不是完整聊天/媒体备份，不自动回滚。没有任何本地存储能保证卸载、清数据或硬件故障后不丢数据。异步会话/批量写入失败有提示，但并非所有失败都自动排队重试。
- 冒险翻译掉格式未取得具体可复现样例，本次没有盲目重写解析；语音继续走既有原生/中转配置。
- 签名私钥不在此源码包内，请保管之前的私人签名备份。不得公开它。
