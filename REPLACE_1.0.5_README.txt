兔版float 1.0.5 累积源码替换包

这是源码工程覆盖包，不是 APK 内部资源更新包，不能在手机更新入口导入。
先备份源码，将本 ZIP 内同路径文件覆盖到原项目根目录。以完整 1.0.0 APK 源码为基准，累计包含此前 1.0.1、1.0.2 与线下修复及 1.0.3 与本次 1.0.5 修改。

安装使用说明见 docs/RELEASE_1.0.5.txt。资源更新机制与维护命令见 docs/RESOURCE_UPDATES.md。
签名私钥与密码不在本包中，继续用原私有签名备份。不要修改包名、本地源或签名。
需要重新构建时先 npm ci；构建脚本会重新生成安卓网页资源，不需要保留旧哈希脚本。
此包不删除用户工程中的额外文件，不包含 node_modules、SDK、APK 或私钥。
