1029 整合更新包

适用：1028 完整源码（已装过当天任一更新包也可以直接覆盖）。本包包含 1028 的圆角输入框、商品详情加号、日程/WVS同步与偶遇、时间轴滚动等累计更新。

安装：
1. 解压后，把 components、lib、styles、scripts 等目录合并覆盖到项目根目录（package.json 所在目录）。不要把整个旧目录删除后再放入本包；本包是增量源码。
2. 用 GitHub Desktop 检查变更、提交并推送，等待 Vercel 重新部署。若已关闭自动部署，手动触发构建。
3. 正常更新保留浏览器原有数据；更换域名或设备时，先在旧站导出数据，再到新站导入。

本轮内容：
- 日历：重新整理简短提示词，去掉每周数量目标。围绕职业项目和重要约定构思，省略固定上班上课健身、吃饭购物探店家务等流水账，日期随事件变化。已生成的旧日程不自动删除。
- 直播：普通随性直播交给平台，不自动写成日历任务；回归宣传、新剧宣传、陪看等专题直播可生成实际日程，沿用公开同步、忙碌和冲突待调整。WVS 混合社区刷新时低频检查空闲和开播意愿，检查间隔持久保存；手动生成 LIVE 仍可使用。有其他忙碌安排或正在另一平台直播时不会新开播，WVS 前台内已有直播遇到其他忙碌安排会结束。YouTube 原有开播习惯逻辑保留。
- 世界线：theqoo、X、小红书优先读取当前进度和近期已公开事件，结合本次上下文检索相关背景与旧历史，用于衔接因果；不再把整份历史每批原样放入公开平台请求。保留平台日常选题和近期话题避重。其他应用原有世界线读取逻辑保留。
- X：大小号的设置里新增“运营与发言方式”。本人、团队、混合运营均可自由描述；留空默认本人正常使用。保留小号的独立对外身份与披露设置。正在关注页下拉仍可手动勾选账号，不新增发帖比例设置。
- 短信和电话：本地上传 MP3/音频，支持试听、替换、恢复默认，URL 入口保留。单个文件上限 10 MB。短信选择后保存；电话需要点击保存。电话恢复默认沿用 Chat 来电提示音，短信恢复默认静音。
- 群聊：输入栏引用预览改用被引用者的群昵称；发送后的引用逻辑保留。
- Chat：多选后新增“合并转发”，选择已有单聊或群聊发送。一张折叠记录卡保存转发时的昵称、头像、时间、正文与媒体引用，展开可查看。一次最多 100 条；原消息后续编辑、撤回、删除不改写快照。接收角色在生成回复时可读取记录内容。记录为只读，不含思维链和原始工具记录，原红包/转账等不会在快照中再次执行。图片、表情和音视频沿用已保存的资源；单独清理这些资源后相应媒体仍可能不可用。围观群不能作为发送目标。

未加入：char 私聊、char 自主转发其他聊天记录。Kakao 通话背景和布局保留。

验证：TypeScript 无报错；正式 npm run build 完成，玻璃样式恢复脚本完成；原有日历/购物/频道/卡片/WVS同步检查与新增脚本 scripts/check-oct29-update.cjs 通过。新卡片与音频设置完成服务端渲染检查。本次未调用真实文字/语音 API，也未完成手机真机点击、音频播放和手势验收；模型实际文风与日程分布更新后使用中观察。


生成状态提示补充版：
- WVS、日历、theqoo、X、小红书新增持续可见的生成状态卡，显示当前任务和已等待时间，不使用虚构百分比。
- 任务结束后保留成功、失败、无新增或提示结果，可手动关闭；下一次生成自动清掉上一次结果。

- 也检查了 YouTube 与购物/外卖：它们已有持续生成/搜索状态，本次保留其原有界面。
- 不额外请求 API，不自动重试或擅自中断现有生成。本轮结果保留在当前 App 实例内，关闭并重新打开 App 后不作为长期任务历史保存。
- 新增检查脚本 scripts/check-oct29-feedback.cjs，覆盖状态切换、成功/失败/无新增判定、旧状态清理和五个入口接入。此版包含前述 1029 整合更新的全部内容。
